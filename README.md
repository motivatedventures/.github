# .github

Organization-wide defaults for the `motivatedventures` GitHub organization.

- `profile/README.md`: the public organization profile shown at
  https://github.com/motivatedventures
- `.github/pull_request_template.md`: default pull request template for every
  repository in the organization that does not define its own

GitHub only applies these files when this repository is public, so everything
here is public. Do not put anything internal in it.
